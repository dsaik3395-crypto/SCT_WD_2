# SCT_WD_2 - Stopwatch Web Application

This is my **Task 02** project for the **SkillCraft Technology Web Development Internship**.

##  Project Description
An interactive and user-friendly Stopwatch Web Application that allows users to start, pause, reset the stopwatch, and record lap times accurately.

##  Features
- Start the stopwatch
- Pause / Resume functionality
- Reset the stopwatch
- Record lap times
- Display lap history
- Clear all laps
- Accurate time tracking (HH:MM:SS:MS format)
- Fully responsive design (Desktop + Mobile)
- Modern and attractive UI

##  Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

##  How to Run
1. Clone this repository
2. Open `index.html` in your browser
3. Or use Live Server in VS Code
